## Release blockers and high-priority follow-up

1. Replace account deletion with an idempotent server-side deletion job or
   tombstone state machine. The current Edge Function deletes Storage, then
   relational rows, then Auth; a later failure can leave partial deletion while
   the client reports failure. Version the missing production schema, RLS
   policies, and `delete_my_account_data` RPC in the repository before changing
   this production path.
2. Implement Sign in with Apple token revocation on deletion. Capture the Apple
   authorization code, exchange and retain the refresh token securely on the
   server, revoke it during deletion, and handle credential revocation.
3. Add a local account-data purge coordinator and generation/user guards so
   entitlement, planning, tour, experience, profile, and preference state cannot
   survive deletion or repopulate after sign-out/account switching.
4. Update `PrivacyInfo.xcprivacy`, App Store Connect privacy answers, and the
   privacy policy for display name and linked visit/location data after final
   privacy adjudication.
5. Replace robotic system narration with a reviewed high-quality voice pipeline.
   Include rights/consent, server generation, audio normalization, caching,
   offline fallback, interruption handling, and real-device listening QA.
6. Redesign `NearMeShelf` cards into compact, content-fit cards so “Around you
   right now” does not obscure the map. Validate narrow iPhone, Max, portrait and
   landscape iPad, Dynamic Type, VoiceOver, and Reduce Motion.
7. Finish scanner lifecycle cancellation/timeout, partial offline-pack status,
   off-main journal image thumbnails, culture deep-link destination selection,
   HTTPS-only deal links, social signup consent, Apple profile-seed consumption,
   and product-specific entitlement filtering/copy.
